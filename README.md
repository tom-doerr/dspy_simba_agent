# DSPy SIMBA Coding Agent

## Prerequisites

- Python 3.8+
- git (optional)
- pip

## Installation

```bash
pip install -r requirements.txt
```

## Usage

Make the script executable (once):

```bash
chmod +x coding_agent.py
```

Then run:

```bash
./coding_agent.py
```

Or simply:

```bash
python coding_agent.py
```
